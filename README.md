### What I'm building

**[Keruani Kabar](https://keruanikabar.com)** · [Google Play](https://play.google.com/store/apps/details?id=com.keruanikabar.app)

A community app for Muara Enim. Neighbours post local news, warnings and things
for sale — and a post can be broadcast into the WhatsApp groups people already
live in, on a schedule, once an admin approves it. Go, PostgreSQL, React Native
and Vue, running in production for real users.

**[wa-confirm](https://github.com/ashafizullah/wa-confirm)** · [npm](https://www.npmjs.com/package/wa-confirm)

Verify that a WhatsApp number really belongs to your user — without ever sending
a message to a stranger. The usual approach texts a code *to* the number, which
is exactly the pattern that gets service numbers banned, and it only proves the
number someone *typed* is reachable. This inverts the flow, so the number is read
off the message envelope and can't be mistyped or borrowed.

Extracted from Keruani Kabar after learning the hard parts in production: senders
whose numbers WhatsApp hides, group ids that pass for phone numbers, and replies
that must never land in a group. Zero dependencies, MIT.
